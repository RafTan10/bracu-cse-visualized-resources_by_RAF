# CSE422 Lab Mid Drills — offline pack

Each `.py` file is a complete lab-style program with ONE blank (the `# TODO` block), the way the lab evaluation gives it to you.

1. Open a drill in VS Code / IDLE, e.g. `lab1_01_astar_expand.py`.
2. Replace the TODO block with your code. Do not edit anything else.
3. Mark it:  `python check.py lab1_01_astar_expand.py`
   - `PASS` = your code behaves like the reference on the paper's input AND on random inputs.
   - `FAIL` = tells you what was wrong.
4. Stuck?  `python check.py --hint <file>`   or   `python check.py --solution <file>`
5. `python check.py` with no file lists every drill and ticks the ones you have passed.

Start with the three REAL ASSESSMENT drills (lab1_01, lab1_02, lab2_01–03) — they are the actual blanks from past lab assessments of this course.
Needs Python 3.8+ and nothing else.
