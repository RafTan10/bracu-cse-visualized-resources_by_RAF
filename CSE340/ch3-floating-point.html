Slides 9–10 · §3.5 Floating Point

Every real number is a sign, a fraction and a power of two.

Integers can't hold 0.75, 6.02 × 1023 or 1.2 × 10−38. Floating point stores a number like scientific notation, but in base 2. The binary point "floats" to sit right after the first 1.

In binary the rule is the same, and the digit before the point can only be 1: ±1.xxxxxxx2 × 2yyyy. C calls these types float and double.

IEEE Std 754-1985

Before 1985, every manufacturer stored floats differently, so scientific code gave different answers on different machines. IEEE 754 fixed one layout that almost every CPU now uses.

FormatBitsC typeS · E · F
Single precision32float1 · 8 · 23
Double precision64double1 · 11 · 52

Double has more exponent bits (bigger and smaller numbers) and more fraction bits (more precision).

Slide 11 · IEEE floating-point format

Three fields, one formula

Every IEEE number is read with the same formula. Learn it once and every encode and decode question becomes plugging in numbers.

x = (−1)S × (1 + Fraction) × 2(Exponent − Bias)

S · sign

1 bit. 0 means non-negative, 1 means negative. Nothing else about the sign is stored anywhere.

Exponent · biased

Stored as actual exponent + bias, so it is always an unsigned number. Single: 8 bits, bias 127. Double: 11 bits, bias 1023.

Fraction · after the 1

The bits after the leading 1 of the normalized number. The leading 1 itself is not stored (the hidden bit). Single: 23 bits. Double: 52 bits.

Hidden bit

A normalized binary number always starts with 1. (1.0 ≤ significand < 2.0). Since that 1 is always there, IEEE doesn't spend a bit on it. The significand is the fraction with the "1." put back.

value 1.0110 × 2⁵ stored 0110 ← fraction only read back 1.0110 ← hardware restores the 1

Bias, for any exponent size

bias = 2^(k − 1) − 1 k = number of exponent bits

How big, how small, how exact

Two exponent patterns are reserved. That single fact gives you the range, the overflow rule and the special values.

Exponent ruler · overflow / underflow check

handout · overflow-underflow detection

Single-precision range · slide 12

Exponents 00000000 and 11111111 are reserved Smallest: exponent 00000001 → 1 − 127 = −126 fraction 000…0 → significand 1.0 ±1.0 × 2⁻¹²⁶ ≈ ±1.2 × 10⁻³⁸ Largest: exponent 11111110 → 254 − 127 = +127 fraction 111…1 → significand ≈ 2.0 ±2.0 × 2¹²⁷ ≈ ±3.4 × 10³⁸

Double-precision range · slide 13

Exponents 000…0 and 111…1 are reserved Smallest: exponent 00000000001 → 1 − 1023 = −1022 ±1.0 × 2⁻¹⁰²² ≈ ±2.2 × 10⁻³⁰⁸ Largest: exponent 11111111110 → 2046 − 1023 = +1023 ±2.0 × 2¹⁰²³ ≈ ±1.8 × 10³⁰⁸

Where numbers live (log scale, positive side)

Anything closer to 0 than the smallest normal value underflows. Anything past the largest overflows. The negative side is a mirror image.

Precision · slide 14

All fraction bits are significant, so the gap between neighbouring numbers is about 2−f of the value.

Single 2⁻²³ → 23 × log₁₀2 ≈ 23 × 0.3 ≈ 6 decimal digits Double 2⁻⁵² → 52 × log₁₀2 ≈ 52 × 0.3 ≈ 16 decimal digits

Slide 15 · handout · Practice Q6–Q8

Decimal → IEEE in six steps

Convert, normalize, bias, sign, fraction, encode. Every encode question is these six steps, in this order.

  1. Convert to binaryInteger part: place values (or divide by 2). Fraction part: multiply by 2 repeatedly and write down each integer part. Keep exactly the number of bits the question says ("consider 10 bits").
  2. NormalizeMove the point until exactly one 1 is before it. Point left → exponent up. Point right → exponent down.
  3. Biased exponentbias = 2k−1 − 1. Biased = actual + bias, written in k bits.
  4. Sign bit0 for positive, 1 for negative.
  5. FractionThe bits after the leading 1. Pad with zeros on the right up to f bits (or cut off extra bits).
  6. EncodeWrite S | exponent | fraction, then group into 4s from the right for hex.

Slide 16 · handout · Practice Q9

IEEE → decimal: run the formula backwards

Split the bits into S, exponent and fraction, then plug them into (−1)S × (1 + F) × 2E − bias.

  1. Get the binaryHex → 4 bits per digit. A decimal or octal pattern (Q9 ii, iii) → convert to binary first, padded to the full width.
  2. Split1 sign bit, k exponent bits, f fraction bits.
  3. SignS = 1 → negative.
  4. Actual exponentbiased − bias.
  5. Fraction to decimalbit 1 after the point is worth 2−1 = 0.5, bit 2 is 0.25, bit 3 is 0.125, …
  6. Final number(−1)S × (1 + fraction) × 2actual exponent.

Slides 18–19 · Practice Q13–Q15

Addition: line up the points first

You can only add significands when the exponents match. So the number with the smaller exponent is shifted right until they do.

Slide 18 · decimal, 4 significant digits

9.999 × 10¹ + 1.610 × 10⁻¹
  1. Align decimal pointsShift the number with the smaller exponent: 1.610 × 10⁻¹ → 0.016 × 10¹ (only 4 digits fit, so the last 0 falls off).
  2. Add significands9.999 × 10¹ + 0.016 × 10¹ = 10.015 × 10¹
  3. Normalize, check over/underflow10.015 × 10¹ → 1.0015 × 10²
  4. Round and renormalize1.0015 × 10² → 1.002 × 10²Only 4 digits fit. If rounding produced 10.00, you would normalize again.

Binary addition / subtraction stepper

slide 19 method
Subtraction is additionA − B = A + (−B). So 18.71 − (−7.01) (Q15) becomes 18.71 + 7.01. When the signs differ, subtract the smaller magnitude from the larger and keep the larger one's sign.
Slides 20–21 · Practice Q10–Q12

Multiplication: add exponents, multiply significands

Exactly like (a × 10x)(b × 10y) = ab × 10x+y. No aligning needed. Then check the exponent for overflow or underflow.

Slide 20 · decimal, 4 significant digits

1.110 × 10¹⁰ × 9.200 × 10⁻⁵
  1. Add exponents10 + (−5) = 5With biased exponents, subtract the bias once from the sum.
  2. Multiply significands1.110 × 9.200 = 10.212 → 10.212 × 10⁵
  3. Normalize, check over/underflow10.212 × 10⁵ → 1.0212 × 10⁶
  4. Round and renormalize1.0212 × 10⁶ → 1.021 × 10⁶
  5. Sign from the operand signs+ × + → +1.021 × 10⁶

Why subtract the bias once?

biased₁ + biased₂ = (E₁ + bias) + (E₂ + bias) = E₁ + E₂ + 2·bias one bias too many ↑ new biased exponent = biased₁ + biased₂ − bias Slide 21: (−1 + 127) + (−2 + 127) − 127 = −3 + 127 = 124

Quick definitions

Exam traps

    Memory hooks

    • "1 ate 23": single is 1 · 8 · 23. Double adds to 64: 1 · 11 · 52.
    • Bias is "half minus one": 8 bits hold 256 values, half is 128, minus one is 127.
    • "Point goes Left, exponent Lifts": moving the point left raises the exponent.
    • Adding needs Agreement: align exponents first. Multiplying doesn't care; it just adds them.
    • All 1s is Infinity when the fraction is quiet (0), and Not a Number when it isn't.
    • Hidden 1: it's always there, so it's never stored. Write the fraction, restore the "1." when reading.
