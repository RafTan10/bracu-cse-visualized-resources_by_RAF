01Core concepts, illustrated

Six ideas that carry most of the chapter's marks.

Registers, not variables

32 registers x0–x31, 64 bits each. x0 is always 0. Arithmetic works only on registers and small immediates: add, sub, addi.

Memory needs ld / sd

Address = base register + constant offset. A[i] of doublewords is at base + 8i. Variable index → slli by 3, add base, ld 0(reg).

Every instruction is 32 bits

Six formats (R, I, S, SB, U, UJ) keep opcode, rd, rs1, rs2 in fixed places. Immediates are split in S, SB and UJ.

Branch on the opposite condition

if (i == j) compiles to bne … Else. Branch offsets are bytes: target − branch address.

Procedures use the stack

Args in x10–x17, result in x10, call with jal x1, return with jalr x0, 0(x1). Save x1 and any s-register you change.

Two's complement

Top bit weighs −2ⁿ⁻¹. Negate = invert + 1. Widen by copying the sign bit (sign extension).

Instruction encoder / decoder

assembly ⇄ 32-bit machine code

What to notice: rd, rs1 and rs2 never move between formats. In sd the stored register sits in rs2 and the immediate is cut in two. Branch offsets are bytes and always even. With the first box ticked, branches use 1100111 like your practice sheet; unticked, they use the official RISC-V value 1100011. In the course setting, 1100111 is read back as a branch, so jalr can't be decoded there.

Two's complement explorer

What to notice: the outlined sign bit flips a value from the top of the range to the bottom. 0111…1 is the largest positive; 1000…0 is the most negative and has no positive partner.

What to notice: A[8] of doublewords is 64 bytes from the base. A constant index goes straight into the offset; a variable index needs a shift and an add first.

05Memory hooks

Formats: "Real Instructions Store Branches Up Jumps"

R, I, S, SB, U, UJ, in that order.

R-type bit order: "Fat Rabbits Run Fast, Rarely Overeat"

funct7, rs2, rs1, funct3, rd, opcode.

Design principles: "Simple Small Good Common"

Simplicity favors regularity · Smaller is faster · Good design demands good compromises · Make the common case fast.

Registers: "t's are temporary, s's are saved"

t0–t6 can be trashed by a call. s0–s11 must look untouched when a procedure returns. a0–a7 carry arguments in and results out.

Stack = plates in a cafeteria

Take the top plate off (addi sp, sp, −8) before you put yours down (sd). Put it back in reverse order on the way out.

"Shift 3 for 8"

Doubleword index → byte offset is slli 3 (× 8). Word → slli 2. Byte → nothing.
